## The Bots

The Crabjar fleet consists of:
- **artix-supervisor** — Manages Artix Linux machines and services
- **ftw3-supervisor** — Oversees GPU compute node operations
- **lappy-supervisor** — Handles laptop development environment tasks
- **sovnode-supervisor** — Coordinates sovereign node operations
- **crabjar-conductor** — Orchestrates multi-agent workflows

Each bot runs on dedicated hardware and provides specialized automation for home-lab management, LLM inference scheduling, and agent orchestration.
