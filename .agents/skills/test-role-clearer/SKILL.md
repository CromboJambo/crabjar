# Test Role Clearer

Clarifies agent vs user authority boundaries in ${PROJECT} sessions.

## Core Principle

${PROJECT} is a pure observer: it detects, reports, and analyzes. It does not execute actions. The user has execution authority.

## Questions

1. "Who is executing this action?" — Agent (${PROJECT}) = observer only, User = execution authority, Neither = system component
2. "What role does this component play?" — Passive observer, active executor, configuration tool
3. "Where does authority reside?" — User has permission to execute; ${PROJECT} only reports
