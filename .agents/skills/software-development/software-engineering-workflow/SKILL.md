# Software Engineering Workflow

This skill provides comprehensive guidance for professional software development workflows covering the full lifecycle from requirements to deployment.

## Core Workflow

1. **Requirements gathering**: Understand and document user needs
2. **Design phase**: Architect solution with appropriate patterns
3. **Implementation**: Write clean, tested code following conventions
4. **Testing**: Comprehensive test coverage (unit, integration, e2e)
5. **Code review**: Peer review process for quality assurance
6. **Deployment**: Safe deployment strategies and rollback plans

## Usage Instructions

### Input Requirements
* Project context and scope
* Development stage (requirements, design, implementation, etc.)
* Team conventions and standards

### Example Prompts
* `/software-engineering-workflow guide me through requirements gathering`
* `Apply professional development workflow to this feature request`
* "What's the proper engineering process for implementing this?"
