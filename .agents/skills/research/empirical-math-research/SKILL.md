# Empirical Mathematics Research

This skill provides workflows for testing mathematical conjectures computationally, exploring patterns through code, and validating hypotheses with numerical experiments before formal proof attempts.

## Core Workflow

1. **Formalize conjecture**: Translate mathematical statement into testable form
2. **Design computational tests**: Create algorithms to verify conjecture across cases
3. **Run experiments**: Execute tests over relevant parameter ranges
4. **Analyze results**: Identify patterns, counterexamples, or supporting evidence
5. **Report findings**: Document computational evidence and limitations

## Usage Instructions

### Input Requirements
* Mathematical conjecture or hypothesis
* Parameter ranges to test (if applicable)
* Computational constraints (time, resources)

### Example Prompts
* `/empirical-math-research test this conjecture about prime numbers`
* `Explore the pattern in this sequence computationally`
* "Verify this mathematical hypothesis with numerical experiments"
