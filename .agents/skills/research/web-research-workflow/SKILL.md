# Web Research Workflow

This skill provides methodology for conducting systematic web research including source evaluation, information synthesis across multiple sources, and proper citation management for comprehensive topic investigation.

## Core Workflow

1. **Define research question**: Clarify what information is needed
2. **Identify sources**: Find relevant websites, articles, and databases
3. **Evaluate credibility**: Assess source reliability and bias
4. **Synthesize information**: Combine findings from multiple sources
5. **Document sources**: Maintain proper citations and references

## Usage Instructions

### Input Requirements
* Research question or topic
* Scope and depth requirements
* Time constraints (optional)

### Example Prompts
* `/web-research-workflow research the current state of Rust async`
* `Conduct systematic web research on this topic`
* "Find reliable sources on this subject and synthesize the information"
