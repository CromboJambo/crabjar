# Engineering Documentation Standards

This skill provides guidelines for writing high-quality technical documentation including status reports, design documents, API documentation, and engineering communications that are clear, concise, and actionable.

## Core Workflow

1. **Identify audience**: Determine who will read the document and their technical level
2. **Choose appropriate format**: Select document type based on purpose (report, spec, guide)
3. **Structure content**: Organize information logically with clear headings and sections
4. **Write clearly**: Use precise language, active voice, and concrete examples
5. **Review for completeness**: Ensure all necessary information is included

## Usage Instructions

### Input Requirements
* Document purpose and audience
* Key information to include
* Any existing documentation standards to follow

### Example Prompts
* `/engineering-documentation-standards write a status report on this project`
* `Create API documentation for this endpoint`
* "Help me write a clear design document for this feature"
