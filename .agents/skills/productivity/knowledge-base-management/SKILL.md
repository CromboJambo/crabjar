# Knowledge Base Management

This skill provides workflows for structuring and managing accumulated knowledge, including organizing information into searchable databases, maintaining documentation hierarchies, and ensuring knowledge remains accessible and current over time.

## Core Workflow

1. **Audit existing knowledge**: Inventory current documentation and information sources
2. **Design structure**: Create logical organization scheme based on content types
3. **Migrate content**: Move existing knowledge into new structure
4. **Establish maintenance process**: Define how new knowledge is added and old knowledge is updated
5. **Implement search and retrieval**: Ensure knowledge is easily discoverable

## Usage Instructions

### Input Requirements
* Knowledge base location (files, database, or mixed)
* Content types to organize
* Access patterns (who needs what information)

### Example Prompts
* `/knowledge-base-management organize my project documentation`
* `Create a searchable knowledge base from these notes`
* "Help me structure this accumulated knowledge for easy access"
